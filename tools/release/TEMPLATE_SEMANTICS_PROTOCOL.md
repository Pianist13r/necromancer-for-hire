## Distinct diagnostic artifact

It exits from the packaged main scene without `--script` or `--path`. `restore` requires exact staged hashes, restores the original project bytes, removes only the two matching generated files, and records source status. Any drift is HOLD for manual inspection; no cleanup by name.

This produces a **new diagnostic PCK with its own SHA**. It must never be substituted for the accepted production PCK, exported as a user build, or called proof that the old accepted PCK itself ran the semantic probe. It tests the release template against the same frozen audio, NetPipe, export preset and source hashes with only the declared main-scene overlay. Production normal PCK boot remains separate evidence. A final candidate needs a fresh binding to its own source and PCK.
